# ExpressionGen

为 Blender 角色模型生成表情的插件。通过自动分区和可编辑的轮廓曲线，制作闭眼、眉毛动作、嘴型、吐舌等表情，并保存为形态键。内置 62 个表情，无需另找带表情的参考模型。

## 下载与安装

需要 Blender 4.0 或以上版本。

1. [下载插件 ZIP](https://github.com/Loki-0228/ExpressionGen4Blender/archive/refs/heads/main.zip)，或点击仓库上方的 **Code → Download ZIP**。
2. 在 Blender 中打开「编辑 → 偏好设置 → 插件」，从安装菜单选择「从磁盘安装」，选中下载的 ZIP。无需解压。
3. 搜索并启用 **ExpressionGen**。
4. 回到 3D 视图，按 `N` 打开侧栏，进入 **ExpressionGen**。

更新插件时，先停用旧版，再安装新版。更新后重新生成表情，以应用修正。

## 第一次生成表情

开始前先保存 `.blend` 文件。按照侧栏中的 1～5 步操作；顶部「下一步」会提示当前应做的操作。

### 1. 选择模型

在「选择需添加表情的模型」中，指定要添加表情的网格物体。

### 2. 生成目标分区

点击「生成 / 更新目标分区」。首次使用保持默认设置即可；插件会创建分区副本，供后续检查和修正。

### 3. 检查与修正分区

点击「选择目标分区副本」，查看脸部、眉毛与睫毛、瞳孔与高光、眼白、口腔、牙齿、舌头是否归类正确。

如有误分，按 `Tab` 进入编辑模式，选中需要修改的面，设置「手动分区编号」，再点击「将所选面标记到此分区」。常用编号如下：

| 编号 | 部位 |
| --- | --- |
| 0 | 面部 |
| 1 | 眉毛与睫毛 |
| 2 | 瞳孔与高光 |
| 3 | 眼白 |
| 4 | 口腔 |
| 5 | 牙齿 |
| 6 | 舌头 |
| -1 | 不参与表情 |

修改完成后退出编辑模式。左右结构一致的模型，可使用「半脸同步」同步分区。

模型带有「颜+」等独立脸部贴片时，也将它们标记为 **0 · Face**，即可随主脸同步变形。

### 4. 轮廓校正

点击「生成 / 补齐校正曲线」，检查眼睑、睫毛、眉毛和嘴唇的曲线是否贴合模型。

需要调整时，点击「选择曲线，Tab 编辑」，移动曲线控制点。需要左右同步时，开启「曲线左右对称」，或使用「镜像当前侧至另一侧」。完成后退出编辑模式。

如果漏检了单根睫毛，可在对应网格的编辑模式中选中这根睫毛的面，再点击「从所选面指定一根上睫毛」。

### 5. 生成、检查并写入

1. 展开「表情选择」，勾选需要生成的表情；可按名称搜索或按类别筛选。
2. 按需调整「强制左右对称」和「风格设置」，点击「按目标曲线生成表情」。
3. 完成后点击「选择结果并检查形态键」，在 Blender 的形态键面板中拖动数值，检查闭眼、嘴型以及牙齿、舌头的位置。
4. 满意后点击「写入目标并恢复显示」，将表情写入第 1 步选定的模型。

生成后会先得到结果副本，确认写入前可继续调整。修改分区、校正曲线或生成选项后，需要重新生成表情。写入时，同名形态键会更新，其他已有形态键保留，并保留覆盖前备份。

## 继续调整表情

- **修改单个表情**：在结果副本上展开「自定义表情 · 曲线编辑」，选择已有表情，点击「添加表情曲线副本」。编辑曲线后，点击「按曲线重新计算并写回表情」。
- **组合表情**：在「组合表情」中调整各形态键的权重，填写组合名称，再点击「一键生成组合表情」。
- **重复使用分区**：在「分区预设库（跨工程）」中保存修正后的分区，之后可在其他工程中加载。

## 常见问题

- **闭眼、嘴型或睫毛效果异常**： 先检查对应部位的分区，再检查校正曲线是否贴合，修正后重新生成。自动结果可能仍需手工微调。

- **缺少某些表情**： 检查是否勾选了该表情，以及对应部位是否存在、分区是否正确。展开「详细信息」查看提示。

- **生成耗时较长**： 可先只勾选几个表情检查效果，再生成其余表情。生成时可继续查看模型，按 `Esc` 取消；调整模型、分区或设置前，请先等待完成或取消。

- **临时查看原场景**： 点击「暂时恢复原场景显示」。最终确认结果后，再使用「写入目标并恢复显示」。
