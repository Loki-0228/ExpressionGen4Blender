# 可迁移自定义表情

适用版本：2.0.0。生成列表只显示勾选框和表情名称，按预设完整幅度生成。取消勾选后，表情仍在滚动列表中；只有搜索和类别筛选会隐藏条目。

## 编辑已生成表情

1. 使用当前版本生成表情，在结果副本上检查形态键。
2. 展开「自定义表情 · 曲线编辑」。选择已有表情，填写写回名称。已有表情留空或选择 Basis 时，从中性曲线开始。
3. 点击「添加表情曲线副本」。插件按照生成结果的实际顶点位移，创建同格式的原生 Blender 曲线。
4. 编辑控制点和手柄。需要左右同步时开启「曲线左右对称」，或使用「镜像当前侧至另一侧」。对称使用模型本地 X 轴和分区的镜像平面，只同步同类、数量对应的曲线。
5. 点击「按曲线重新计算并写回表情」。编辑被换算成局部坐标中的归一化偏移，经过表情与约束求解，写入形态键及口内联动。覆盖已有形态键前，会新增「修改前备份」形态键。
6. 写回后，曲线副本更新为约束求解后的实际形态。可迁移规则同时进入当前场景的规则库，可重新生成和导出。

规则使用曲线特征和局部比例，不携带测试模型顶点编号。更换模型后重新识别和绑定；部件缺失或识别条件不满足时跳过该表情并给出原因。旧结果需用当前版本重新生成，才能取得变形曲线记录。已确认应用的结果需重新生成后编辑，避免使用失效的原模型拓扑对应。

一侧眉毛包含多片位置重叠的网格时，未单独编辑的眉毛曲线会跟随已编辑曲线；单独编辑的曲线保留自身目标。这项跟随依据曲线的空间接近程度和覆盖范围，不依据模型名称。派生平移和规则间引用保留采样点对应，避免重复重采样引入额外弯曲。参数为零且没有实际位移的规则不会激活新的变形部位。

普通校正曲线的编辑直接改变下一次生成的输入；表情曲线副本通过写回按钮更新指定表情。两者分别登记，不会互相覆盖。

## 使用面片雕刻曲线

1. 选择一条校正曲线或表情曲线，展开「面片雕刻曲线」。转换范围可选当前组可见曲线或当前组选中曲线。
2. 设置面片宽度比例及纵横细分，点击「合并为面片并雕刻」。所有面片位于一个网格物体中，每条曲线对应独立材质和面组，可据此选择或隔离。
3. 雕刻或编辑顶点，保留网格拓扑。不要使用动态拓扑、重构或增删顶点；「取消」会删除临时面片并保留原曲线。
4. 设置「写回拟合段数」（1～64），点击「写回曲线并删除面片」。插件提取各截面中心，以固定端点的整体三次样条平滑拟合，写入原曲线，随后删除临时网格。段数增加可保留更细的弯曲。
5. 普通校正曲线重新生成表情后生效；表情曲线副本继续点击「按曲线重新计算并写回表情」。若开启曲线左右对称，单侧编辑同步到另一侧；两侧都在面片内时以 X 正侧为准。

面片写回保留曲线原身份、基准采样和分区绑定。来源曲线在编辑期间改变、被删除或重新生成时，会阻止写回并保留面片。表情曲线副本也使用校正曲线的整体平滑拟合，避免把每个网格采样点直接当作控制点。

## 表情关系与对称

在「自定义表情 · 可迁移规则」选择定义方式，再保存规则。

| 定义方式 | 内容 |
| --- | --- |
| 曲线计算规则 | 设置识别与计算规则，可声明「允许强制左右对称」及「特殊表情」 |
| 取来源的左侧或右侧 | 选择来源表情及 X 正/负侧；眼眉在求解前选择分支，其他部位在中线附近连续衰减 |
| 取满足条件的网格 | 条件同时成立；按当前分区编号及模型包围盒中的 X/Y/Z 位置比例筛选；-2 表示所有分区 |
| 组合已有表情 | 逐项填写来源表情名称及权重，依赖必须无循环 |

子表情和组合不会因生成界面的对称开关而复制到另一侧。内置的单眼闭眼及单侧眉毛已登记为相应双侧动作的子表情。普通组合先合成规则；包含局部网格子表情时合成已求解位移，权重和超过 1 时归一化，再执行接触和防翻折检查。

强制对称以 X 正侧为准。只有网格、分区和中性形状匹配时才能可靠镜像；拓扑也匹配的独立眼眉动作可以复用一侧计算。不能对应或约束冲突的原因记录在结果报告中。该开关不承诺整批生成耗时减半。

## 定义识别和计算规则

在「自定义表情 · 可迁移规则」填写名称，可选填一个内置基础表情。依次设置三页，然后保存规则。

| 页面 | 设置内容 | 生效方式 |
| --- | --- | --- |
| 识别曲线 | 分区、左右侧、类型、候选序号、位置比例、大小占比、拓扑条件 | 根据当前模型取得曲线；「显示识别曲线」查看识别结果 |
| 计算规则 | 原始曲线、目标曲线或目标规则、接近程度、影响项 | 先计算依赖，再计算当前规则；影响项逐项相乘 |
| 界面参数 | ID、名称、默认值、上下限、是否显示 | 公开参数出现在「表情选择」下的「自定义规则参数」中 |

曲线、规则和参数 ID 以字母开头，后续可含字母、数字和下划线，最多 64 字符。修改 ID 时也要修改其引用。不存在的引用、重复 ID 和循环引用会阻止保存或导入。

### 识别方式

| 方式 | 输入 | 适用情况 |
| --- | --- | --- |
| GUIDE | 部位、左右侧、候选序号 | 当前编辑的校正曲线 |
| BOUNDARY | 分区及侧别 | 分区实际拓扑边界环 |
| SECTION | 分区、截面轴、0～1 位置 | 分区三角面与截面的交线 |
| DERIVED | 另一曲线 ID、局部偏移 | 从已识别曲线推导新曲线 |

识别条件全部满足后，按候选序号取曲线。GUIDE 按已有标识排序，其余候选按本地坐标中心排序。候选数量变化时，应补充条件。

位置、尺寸和弧长以参照曲线包围盒的最大边长归一化；无参照时使用当前模型包围盒的最大边长。中心比例是两个包围盒中心的相对位移。宽高比为 X 跨度 / Z 跨度，Z 有很小的下限以避免除零。拓扑条件包含所属分区的连通块数、边界环数，以及曲线是否闭合、绑定顶点数。GUIDE 的连通块和边界环特点取自指定分区。不进行跨模型最近面匹配。

新建曲线用于眉毛、睫毛、眼缘或嘴唇时，绑定到同部位已有校正曲线，优先选拓扑顶点有重叠的对象。Face 的 CUSTOM 曲线直接控制绑定点并通过位移场传播；已有眼口轮廓顶点仍服从专门约束。其他分区的 CUSTOM 曲线可作识别或影响参照，直接形变应选择对应部位类型。

### 原始与目标曲线

目标选择以下一种：另一识别曲线、一条依赖规则的计算结果，或归一化偏移采样。

「创建原始与目标曲线供编辑」创建原生曲线。修改目标后保存，会将差值换算为归一化采样。如果原来引用其他曲线或规则，编辑后该条目标改为独立偏移；未修改则保留引用。设置「归一化目标偏移」会替换为统一偏移。

局部第一轴沿曲线首尾方向，第二轴为正交化的本地 Y，第三轴是前两轴叉积；长度单位是曲线弧长。闭环首尾方向退化时采用本地 X。偏移按原始曲线参数插值，不按偏移向量的弧长重新排列。

```text
每项影响 = 输入特点在指定范围中的比例，线性映射到指定输出范围
接近程度 = clamp(规则程度 × 绑定参数 × 各项影响乘积, 0, 1)
曲线位移 = (目标曲线 − 原始曲线) × 接近程度 × 表情幅度
最终网格 = 当前模型绑定 + 连续位移场 + 部位附着与接触约束
```

影响项可读取其他曲线或分区特点，以原始曲线作为比例参照；超出输入范围取端值。多个规则作用于同部位时叠加位移，再共同求解约束。

公开参数限定在 0～1，不能关闭防翻折、眼部深度、闭眼方向、睫毛附着、闭合接缝、上下唇次序、口内连接、牙齿跟随和吐舌出口约束。目标可能无法完全实现，求解报告会列出残余冲突。

闭眼优先遵守上眼缘不向上、下眼缘不向下，以及共同眼角高度和接缝；随后遵守下眼睑上移限额，在可行范围内保留曲率。不为保持形状整体降低外眼角。单段三次曲线无法满足编辑轮廓时，以方向边界为准并记录曲率冲突。

## 导出和读取

「导出全部规则表格与 JSON」写出两个同名文件：Markdown 将每个表情的多条准则分行列出，注明数值路径和实现；JSON 保留完整采样、数值、依赖、约束和界面参数，可用「读取规则 JSON」导入。

内置表情使用 `builtin_v1`，导入时核对配方版本。修改内置表情应创建 `curve_rules_v1` 规则，或从表情曲线副本写回，不直接修改内置记录。文件不执行脚本。规则保存在当前 `.blend` 场景中，需保存场景或导出文件。

随包提供 `expression_rules.md`、`expression_rules.json` 和 `custom_expression_example.json`。示例为 X 正侧轻微眯眼，展示曲线引用、大小占比条件、特点影响和公开参数。

## 组合表情

独立「组合表情」面板列出形态键滑块。调整后点击「一键生成组合表情」。程序组合各表情实际生成的配方，重新求解轮廓与约束，再新增形态键。原始项保留，权重归零，新组合设为 1。

## 验证范围

2026-10-13 在 Blender 4.5 后台场景实测 PING 与月野兔：原生曲线编辑、单侧镜像、写回、覆盖前备份、JSON 导入导出、半幅与全幅参数、GUIDE／BOUNDARY／SECTION／DERIVED 识别、规则引用及影响项计算。样例「憋笑失守」从 Basis 的八条眉眼与嘴唇曲线绘制，未引用内置表情作为基础。

约束测试包括交叉的上下眼睑与上下唇目标、连续形态键权重下的脸皮翻折，以及极端目标求解后重新计算正常表情。单排牙的唇缘贴合受到对侧嘴唇限制。检测采用有限采样和数值容差；报告仍保留口内接触与睫毛附着残差，不能据此保证任意目标、任意模型均无穿插。

Vody 嘴唇识别已补充独立下半脸支持。中性副本识别出 24 个唇缘顶点，与 Original「あ」张口后的边界及上下分支对应；识别过程不读取原始形态键。缩放、反向面序、面片重排与前方遮挡测试通过。PING、月野兔的识别顶点和方法与修正前一致。

同一份「憋笑失守」JSON 已在 Vody 生成，并完成参数、曲线识别和约束测试。原有校正曲线、分区及 Original 的 64 个形态键保持不变。嘴部变形固定非轮廓外边界，避免上下脸皮接缝拉开；本样例最终 Face 翻折检查和接缝位移差为零。这次核验不代表 Vody 全部口型和吐舌均已通过。
