# 材质表情

适用版本：2.1.6（开发分支）。材质表情用独立的透明贴图卡片表现眼影、腮红、汗滴、星星眼、泪痕等效果，不再靠变形主网格。

## 目影

目影默认自动生成，一般不需要手工标记。

- **模型已有目影时不创建**：分区 13（界面编号 7）已标记，或材质名带 `目影`、`眼影`、`アイシャドウ`、`EyeShadow` 时，直接使用模型自己的眼影，不再叠加卡片。
- **没有时按眼白生成**：取眼白分区（编号 3）的网格，只保留其上方 **1/3**，沿轮廓采样后略向外扩（默认 1.12 倍），逐点贴合眼球弧面，形成顺着眼睑走向的弧形暗带。可通过卡片的「覆盖比例」和「向外扩展」调整。

若某个模型的眼白与眼睑分得太开，可以手工标记目影分区：选择分区副本，`Tab` 进入编辑模式，选中眼影相关的面，在「所选面分区」里选 **7 · 目影** 后点击「标记所选面」，退出编辑模式重新生成。

目影只提供贴图位置，不参与眼睑变形求解。

## 三种卡片

展开「材质表情」即可看到卡片列表。

| 类型 | 用途 | 关闭时 | 开启时 |
| --- | --- | --- | --- |
| 贴合分区 | 眼影等贴合某一分区的效果 | 缩进脸壳正面投影内 | 贴合分区表面，略微浮起 |
| 整体曲面罩 | 腮红（脸红） | 沉入皮肤下方 | 罩住整张脸的外壳 |
| 定位平面 | 汗滴、感叹号等任意位置的小贴图 | 沿法线缩进头壳 | 出现在空物体的位置 |

贴合分区需要指定分区编号；曲面罩使用整个 Face 分区；定位平面需要一个名称以 `EK_J_` 开头的空物体，平面位置与朝向取自该空物体。

每张卡片在生成后是独立物体，带有形态键：`Basis` 是隐藏态，其余每个表情键是显示态。卡片键的值自动跟随结果模型上同名形态键，所以打开模型上的「星目」，卡片就出现；关闭就收回脸壳内。

## 打包的表情

以下表情随插件提供，出现在「表情选择」列表里：

- **贴图卡片**：はぁと、星目、涙、汗颜、111、1111、11+、怒、！、？、！！、汗
- **程序化曲面罩**：脸红（由 Face 分区生成柔和腮红，不使用贴图）
- **眼型与嘴型**：はぅ、はちゅ目、手前、やっかい、悲しい、ｷﾘｯ、喜び、慈愛、驚かす、じと目2、笑い2、ムッ、怒った、大口、倒ω、痛み、∧、口上、心配する、えー 等 38 个

## 贴图

插件自带一张卡片贴图（`data/textures/bq.png`），涵盖上述卡片用到的全部图形。

要用自己的贴图，在「材质表情 → 参考卡片贴图」中指定文件。贴图需带透明通道（PNG 或 TGA），卡片按参考模型的 UV 布局取样，因此自定义贴图应保持相同的图集排布。

眼影与腮红卡片可以留空贴图，此时是纯色卡片，适合先确认位置再换成正式贴图。


## 关闭态与写回

未启用的卡片除缩入脸壳外，还会保持透明，避免其他表情收缩眼孔后露出隐藏贴片。透明度保留贴图原有的 Alpha，并跟随该卡片的表情键；分批写回后由目标模型控制，不会串到另一批结果上。旧结果需要重新生成材质表情并写回，才会带上此联动。

## 已知限制

- 卡片位置取自参考模型的头部比例，换到头部比例差异很大的模型上可能需要微调。插件会在放置时把卡片推到该模型实测的皮肤与眼球表面之前，避免被脸挡住；但左右位置仍按比例缩放。
- 参考卡片贴图版权归原作者，随模型分发时请遵守该模型的使用规约。
- 材质表情卡片是独立物体，不写入目标网格的形态键；导出到 MMD 或 PMX 时需要在下游软件中转换。
